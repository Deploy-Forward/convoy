# Audits

Point-in-time adversarial reviews of this repo, kept because the honesty bar in
`SPEC.md` is easier to hold when the receipts are public.

**Read these as dated snapshots, not as current status.** Each audit states the
commit it was run against. A finding marked RED there may since have been fixed,
reworded, or superseded — check `SPEC.md` and `git log` for where things stand
now. Nothing in this directory is normative; `SPEC.md` and `CANON.md` are.
