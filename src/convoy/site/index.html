How it works

  1. 01 · Attach

    Connect your client to https://convoy.bot/mcp and initialize one convoy thread.

  2. 02 · Onboard / roster

    Declare which harnesses you already run. Convoy reports PATH and availability honestly.

  3. 03 · Send

    Dispatch headless synapses to a chosen harness and receive compact cards back in your main thread.

  4. 04 · Bring up

    Open terminals only when you want them. Default MCP flow remains headless and controlled.

Objects

thread

The durable circuit. One visible working thread bound to one convoy context.

cvy_id

The convoy identifier that ties seats, pointers, and feed events to the same source of truth.

neuron / harness

One native harness session (grok, claude, codex, cursor-agent, agy). Grok Bot is the conductor, not a neuron.

synapse

One send into one harness that returns a compact result card, stamped back to the shared feed.

Honesty contract

  • Bring your own harness login. Convoy does not wrap model vendors.
  • MCP attach is live at /mcp; POST is the active JSON-RPC transport.
  • Live resumed send is intentionally refused today to avoid hijacking an existing interactive session.
  • No invented usage numbers, sessions, or synthetic model identities.
