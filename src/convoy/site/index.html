One thread. Send work to native neurons. Use bring_up when you want terminals.

Convoy keeps one MCP root at https://convoy.bot/mcp, routes work to your existing CLIs, and grounds every neuron in one durable thread state.

https://convoy.bot/mcp

How it works

  1. 01 Attach one MCP root: https://convoy.bot/mcp. A named thread is a --root binding, not a second MCP URL.

  2. 02 Run onboard / roster to name harnesses you already have. Convoy reports PATH truth and does not invent a roster.

  3. 03 send runs a headless synapse (pointers in, compact card out). feed/context stay pointer-first, and live send keeps a no-steal guard on interactive --resume.
